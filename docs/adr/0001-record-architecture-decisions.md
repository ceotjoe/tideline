# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-10-01

## Context
Tideline is maintained by volunteers over years. Decisions must be understandable later.

## Decision
- Every significant decision is recorded as an ADR in `docs/adr/NNNN-title.md`, using `0000-template.md`.
- ADRs are immutable once accepted. A change of mind is recorded as a new ADR that supersedes the old one.

## Consequences
- Writing an ADR is part of the Definition of Done whenever a feature involves a decision.
