# 0012. Internationalisation with gen-l10n and ARB

- Status: accepted
- Date: 2026-10-01

## Context
- All strings must be translatable from day one, by contributors who don't know Dart.
- Since Flutter 3.32 the synthetic `flutter_gen` package is gone, and gen-l10n generates into the source tree.

## Decision
- ARB files live in `app/lib/l10n/arb/`, with English as the template. Generated code goes to `app/lib/l10n/generated/`
  and is committed.
- Ship English and German. A pseudo-locale (`en_XA`-style, accented and expanded) is used for testing, plus an RTL
  pseudo-locale (`ar_XB`-style) that is **only** for tests and debug builds.
- A test fails when a `Text`, tooltip or semantics label in `app/lib/src` contains a string literal outside allow-listed
  non-language tokens.
- The in-app language override is stored in settings, falling back to the system locale.
- **ADIF and wire formats are never localised.** Locale-aware formatting is applied only in the presentation layer.

## Consequences
- Translators only touch ARB files (`docs/translating.md`).
- Weblate or Crowdin can be adopted later without code changes.
