# Keyboard shortcuts

Tideline works fully from a hardware keyboard on desktop, iPad and Android tablets. Press **Ctrl + /** (**⌘ /** on Apple devices) or **F1** at any time to see every shortcut in the app. Shortcuts for the logging and contest screens work only on those screens.
