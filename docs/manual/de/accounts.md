# Mehrere Wavelog-Konten

Du kannst mehr als ein Wavelog verbinden, zum Beispiel dein eigenes und das einer Clubstation. Ein Konto ist **zum
Loggen in Verwendung**: Der Log-Bildschirm, Contests und Aktivierungen nutzen es. Wartende QSOs aller Konten werden
trotzdem an ihren jeweiligen Server gesendet.

## Konto hinzufügen
1. **Einstellungen → Wavelog-Konten → Konto hinzufügen.**
2. Gehe die gleichen Schritte durch wie in der [Ersteinrichtung](first-setup.md): Server, Token, Stationsstandort.
3. Das neue Konto wird **nicht** automatisch eingeschaltet. Seine Seite öffnet sich; wähle **Zum Loggen verwenden**,
   wenn du es nutzen willst.

Haben zwei Konten denselben Namen, hängt Tideline eine Zahl an („Club 2“). Du kannst ein Konto jederzeit umbenennen.

## Konto wechseln
- Auf dem Log-Bildschirm erscheint das Kontomenü (zwei Pfeile und der Kontoname), sobald es zwei Konten gibt. Wähle das
  Konto; eine Meldung bestätigt „Es wird in … geloggt“.
- Oder öffne **Einstellungen → Wavelog-Konten**, das Konto, **Zum Loggen verwenden**.
- **Solange eine Contest-Sitzung oder eine Aktivierung läuft, kannst du nicht wechseln.** Beide gehören zum Konto, und
  ein Logeintrag im falschen Konto fiele schwer auf. Beende zuerst die Sitzung oder Aktivierung.

## Was zu einem Konto gehört
Seine QSOs, Standorte, der Sync-Stand samt Verlauf, Contest-Sitzungen, Aktivierungen und der Index „Schon gearbeitet“.
**Import und Export** (Sicherheit und Backup) wirken auf das Konto in Verwendung und nennen es.

Der **Sync**-Bildschirm zeigt, wie viele QSOs pro Konto warten.

## Konto entfernen
**Einstellungen → Wavelog-Konten →** das Konto **→ Konto von diesem Gerät entfernen.**
- Tideline sagt dir zuerst, wie viele QSOs des Kontos Wavelog noch nicht erreicht haben (sie gingen verloren).
- **Log exportieren, dann entfernen** speichert zuerst eine ADIF-Datei. Wird das Speichern abgebrochen, bleibt das Konto.
- **Konto von diesem Gerät entfernen** entfernt es sofort.
- Entfernt werden QSOs, Sitzungen, Aktivierungen und Token des Kontos **nur auf diesem Gerät**. Dein Wavelog bleibt
  unverändert.
