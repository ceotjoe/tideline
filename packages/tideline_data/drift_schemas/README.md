# Schema dumps

One JSON dump per released schema version, generated by drift. **Never edit these by hand.**

To change the schema:
1. Edit the tables in `lib/src/database/tables.dart`.
2. Bump `schemaVersion` in `tideline_database.dart`.
3. Run `dart run drift_dev make-migrations` in `packages/tideline_data`. This writes the new dump, the step-by-step
   migration helpers and migration tests under `test/drift/`.
4. Write the migration step in `TidelineDatabase.migration` and fill in the generated test with real data.

CI regenerates these files and fails if the committed ones differ (`tool/check_generated.sh`). A schema change without a
version bump is therefore caught automatically.
