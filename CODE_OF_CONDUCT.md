# Code of Conduct

Tideline adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming, be patient, assume good intent, and remember that people here range from
newly licensed operators to seasoned contesters. Harassment and personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer via a
[GitHub private message or a confidential issue to the maintainer](https://github.com/ceotjoe).
All reports are handled confidentially. Enforcement follows the Contributor Covenant's
enforcement guidelines.
